# coding-agent-test

Small Java command-line example that runs a binary search against a sorted list of integers.

## Requirements

- Java Development Kit (JDK) 8 or newer

## Compile

```bash
javac src/Main.java
```

## Run

Pass the sorted array values first and the target value last:

```bash
java -cp src Main 1 2 3 4 5 6
```

Example output:

```text
Result index: -1
```
